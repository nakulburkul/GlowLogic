# GlowLogic (GlowGuide)

A skincare catalog and product discovery project that started as a Python Tkinter desktop prototype and expanded into a Django web application (`glowguide_web` and `shop`) with product catalog management, image/link helpers, and environment-based configuration.

## Tech Stack
- **Backend & Web:** Python, Django (`glowguide_web`, `shop`)
- **Desktop Prototype / Utilities:** Python (`Design1.py`, `Design 3 idea.py`, `Design FInal.py`, `database.py`, `db_clean.py`, `amazon_*.py`)
- **Frontend:** HTML (`shop.html`), CSS, Static assets (`static/`, `product_images/`)

## Local Setup
1. Create and activate a virtual environment (`venv`), then install dependencies.
2. Configure your `.env` file (do not commit `.env`).
3. Run migrations and start the Django development server from the project root.
